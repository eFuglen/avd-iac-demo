
# Azure Virtual Desktop Infrastructure as Code

This repository contains Bicep templates for deploying Azure Virtual Desktop (AVD) infrastructure using Infrastructure as Code (IaC) practices.

## Overview

This project provides automated deployment of Azure Virtual Desktop resources including:
- Host pools
- Session hosts
- Application groups
- Workspaces
- Supporting infrastructure (networking, storage, etc.)

## Prerequisites

- Azure CLI installed and configured
- Azure PowerShell module (optional)
- Appropriate Azure subscriptions and permissions
- Bicep CLI installed

## Getting Started

1. Clone this repository
2. Review and customize the parameter files
3. Deploy using Azure CLI or Azure DevOps pipelines

## Structure

```
├── bicep/              # Bicep template files
├── parameters/         # Parameter files for different environments
├── scripts/           # Deployment and utility scripts
└── docs/              # Additional documentation
```

## Deployment

Instructions for deploying the AVD infrastructure will be provided in individual template documentation.
